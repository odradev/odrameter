Odrameter

How many Casper transactions use Odra: they execute at least one contract written in the framework, or install one.

How it is counted. The scanner fetches every block in the window from a node's RPC and, for each transaction that runs wasm, reads the execution effects to see which contracts were touched. A contract counts as written in Odra when its wasm contains the Odra installer's argument names (odra_cfg_*). Native transfers and auction operations run no contract code, so they only count towards the total. Failed transactions are counted when they targeted an Odra contract.
